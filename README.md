# Shamble Chamber


(screenshot)


Step into the chaos of endless zombie waves in a maze of shelves and endless aisles, there is no way out so breathe while you can and enjoy the beauty amidst the chaos. Although you are given infinite amounts of ammo, each gun's magazine could only fit so much.

### How to play:
- Use your guns to take down zombies
- Tactically flee from the scene if emergency reloading is necessary
- Survive as long as possible!


### Controls:
- Use [ W, A, S, D ] to move around
- [ Mouse left button ] to shoot
- [ R ] to reload the guns
- [ 1, 2, 3 ] to switch between guns


### Made using:
- Godot game engine and coded in its native language, GDscript
- Affinity for textures and design
